标题通栏、按钮统一镂空、按角色发色实时换肤；版本升到 1.1

## 1) 标题移到卡片之外，并左右填满屏幕

- 标题从卡片①内部移到页面最顶部（卡片之外）
- 容器去掉左右 16dp 内边距，改为**五张卡片各自带左右外边距**，
  标题才能真正通栏
- 字号方案换过一版：
  * 先试 autoSizeTextType=uniform（11~46sp）—— **实测填不满**，
    只到屏幕约 3/4 处。它在 maxLines + ellipsize + wrap_content 组合下收敛不准。
  * 改为 MainActivity.fitTitleToWidth()：用 TextView 自己的 paint
    （含 bold 与 typeface）以 400px 基准量出文字宽度，再按比例缩放到可用宽度。
  * 实测标题 bounds = x 0..1440，**正好等于屏宽**。

## 2) 所有按钮统一镂空样式

新增 AccentTheme，按钮背景不再由 XML 写死：
  drawable/btn_ghost_bg.xml 只作参考，真正下发给按钮的是代码生成的
  StateListDrawable（普通态=透明底+描边；按下态=同色淡底；禁用态=更淡描边）。
themes.xml 里 PrimaryButton / BigButton / CardAction 都去掉了 android:background，
只保留尺寸排版，颜色一律由强调色下发。

## 3) 按角色发色实时换肤（核心）

新增 AccentTheme：
  extractHairColor(bitmap)
    只看上 45%（头发都在头部附近），滤掉透明、近灰（饱和度<34，含黑白描边）、
    过暗(<60)、过亮(>235)，按 5bit/通道量化后取出现次数最多的一桶；
    样本数 <12 视为不可信，返回 null。
  accentFrom(hair)
    抬高饱和度(>=0.50)与明度(>=0.86)：很多角色是浅粉/亚麻色，
    直接当按钮文字会糊在深底上。
  apply(ctx, root, accent)
    遍历视图树统一上色：
      所有 Button        -> 镂空描边 + 强调色文字
      SeekBar            -> progressTintList / thumbTintList
      EditText           -> backgroundTintList（下划线）
      tag=card 的容器     -> 卡片底与描边
      登记过的 TextView   -> 标题/权限入口用强调色；当前值等用淡化强调色
  派生色：pageBg(强调色混入页面底 7%)、dimText(次要文字混入 42%)。

触发时机：进入页面时、以及**每次切换形象时**立刻重算并重绘。
强调色另存 Prefs.accentColor，供下次启动先上色。

## 4) 卡片底色不变（用户要求）

cardBg() 直接返回固定中性深色，不混强调色 —— 只让描边、按钮、文字跟发色走，
整页不会因为发色太艳而糊成一片。

## 5) 版本号

versionCode 1 -> 2，versionName "1.0" -> "1.1"。

- 权限入口蓝/金下划线 + 绿勾；滑条、输入框下划线、按钮描边全部跟随
- 卡片底色保持中性深色 ✓
