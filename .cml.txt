## 1) 死代码清理

A 区尺寸调节 UI 早在 506915b 就被用户取消，但它留下了一整套机制成为死代码，
而且**有隐患**：ticker 里有这么一段
    if (guideVisible()) { need = true }
    else if (lastWinW == bounds().width()) { restoreWindowSize(); ... }
guideVisible() 现在恒为 false，于是只要窗口宽度**恰好等于屏宽**（宠物尺寸很大时
可能发生），就会误判成"指示线刚消失"并重置窗口尺寸。

删除：
  PetView   : guideUntil / guidePaint / guideVisible / flashGuides / drawGuides、
              onDraw 里的指示线绘制、placeWindow 里的整屏分支、restoreWindowSize、
              ticker 里的指示线分支
  PetService: ACTION_PREVIEW_ZONE 与 previewZone()
  Prefs     : zoneW / zoneH / applyZoneSize / KEY_ZONE_W / KEY_ZONE_H
  MainActivity: applyZoneSize 调用、一段 A 区调节的遗留注释
  布局/strings: 上一轮已删

保留：PetState 里的分区几何（A_W_DEFAULT/A_H_DEFAULT、zoneOf、centerSideDist、
HYSTERESIS_PX 等）仍在实际使用 —— 只是不再可调。
