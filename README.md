# DeskBand · 桌宠

把喜欢的角色放到 Android 桌面上当悬浮窗桌宠：可拖动、吸附屏幕四边、点一下会跳、贴边时还能压缩回弹。

> **深入实现笔记见 [ENGINEERING.md](ENGINEERING.md)** —— 里面记录了窗口策略、吸附判定、
> 动画曲线、以及开发过程中踩过的每一个坑。想改这个项目的话，那份文档比这份有用得多。

| 项 | 值 |
|---|---|
| 包名 | `com.dsh.deskpet` |
| 版本 | 2.1.0 |
| 最低版本 | Android 8.0（API 26） |
| 目标版本 | Android 16（API 36） |
| 依赖 | **纯平台实现**，无 AndroidX / Material —— 包体小、构建面窄 |
| 语言 | Kotlin |

## 功能

### 桌宠本体

- 悬浮窗常驻桌面，**窗口只有宠物那么大**（不是整屏）—— 所以窗口之外的触摸会正常落到桌面
  和其他 App 上，不会挡操作
- 自由拖动，1:1 严格跟手，无阻尼
- 吸附屏幕**四条边与四个角**，带位置补间 + 小回弹
- 朝向随位置自动变化：贴侧边旋转 90°、贴上沿倒挂、左侧自动水平镜像
- **点击**：压扁再弹起，落地还有一次轻回弹；弹起方向永远朝屏幕内侧
- **长按**：按住持续压缩（最深 50%），松手回弹 + 向上弹起 + 落地回弹，深度与按压时间成正比
- **静止**：吸附落位后进入轻微呼吸晃动，**吸附边全程不动**

### 设置界面

| 卡片 | 内容 |
|---|---|
| 当前形象 | 选择角色。名称框展开二级菜单，逐项选择、行间横线分隔；**一页 5 行，再多就在菜单里滚动**（右侧有滚动指示条） |
| 自定义形象 | 新增 / 管理自己的角色（见下） |
| 呼出回弹 | 弹出高度、总时长、回弹幅度 |
| 呼吸 | 呼吸幅度与周期 |
| 边框回弹 | 压缩幅度、时长 |
| 通知栏内容 | 自定义常驻通知文案（留空用默认）。**每个形象各自一份**：换角色即换文案 |
| 外观模式 | 跟随系统 / 浅色 / 深色，一点即换 |
| 权限 | 悬浮窗与通知权限，实时显示 ✓ / ✗（在页面最底部） |

三张动效卡片都有**开关 + 滑条 + 数值输入 + 恢复默认**，滑条与输入框双向联动。

### 主题色跟随角色

程序会从素材里**提取头发的主色调**作为强调色 —— 卡片边框、按钮描边、标题都跟着它走，
换角色即换主题色。切浅色 / 深色时会自动调整明度以保证可读性。

### 自定义形象（2.1.0）

不用改包也能加角色：**自定义形象**卡片默认只是一横条，两个按钮：

| 按钮 | 行为 |
|---|---|
| **新增** | 卡片向下展开表单：形象名称 + 两张素材。按钮本身变成**保存**、右边那个变成**取消**；保存后恢复成一横条。名称框自带**浅色占位**（留空时会用的默认名，如「自定义人物1」），一输入就消失 |
| **管理** | 卡片向下展开已有形象的标签列表（每行两个），标签右侧的红色错号**点一下就变成「确认删除」**，再点才真删（两步，没有弹窗）；**此时右上角的「取消」也变红**，点它先退回管理列表；按钮本身变成**取消** |

**取消**＝**退一级**：管理态下有标签正等着「确认删除」，就先退回管理列表（那个标签复位）；
再点一次才收回一横条。在新增态点「取消」则是放弃本次新增（已填的名字与已选的图一起清掉）。
管理列表为空时提示「尚无自定义形象，点击新增按钮以添加」。

素材要求：

- **主素材（必选）** —— 就是「正立」那一张（头朝上），对应内置素材的 `upright.png`。
  没加就点保存不会生效，提示「须添加主素材」。
- **角落素材（可选）** —— 对应内置素材的 `corner.png`：**朝向左上**的「窝在右下角」姿态，
  贴四个角时用。**不加也不提示**：角落状态直接拿主素材当角落素材用（能用，只是看着像"站着"）。
- **必须是透明底 PNG**。背景不透明的话：人物会连背景一起画出来；逐像素命中判定失效
  （整块矩形都归桌宠，挡住下层图标）；发色提取会取到背景色，主题配色跟着背景跑。
  （纯白／灰底会被发色提取过滤掉、退回默认青色，但"挡住下层"与"画出方块"这两条躲不掉。）
- **左右不用单独出图**：左边 = 右边水平镜像；上方 = 下方上下翻转（实测像素差 0.00）。
- **长边 ≥1280 最好**：超过 1280 会自动缩到 1280 再落盘，**小于 1280 不会被放大** ——
  尺寸拉满（5×）时人物约 1267px 高，所以 1280 是"放到最大也不糊"的门槛。
- **四周留白随意**：定位按非透明像素的包围盒算，留白不影响。
- 别带边框 / 圆角卡片 / 文字水印；带 EXIF 旋转的 JPEG 不会被纠正（可能躺倒）。

保存后**不会立刻换人**：新角色只是出现在「当前形象」的二级菜单里，要去那里选它才启用。

落盘位置是应用私有目录（卸载即消失，不需要任何存储权限）：

```
filesDir/custom_pet/<id>/
├── pet.json      与 assets 里的格式完全一样
├── upright.png   主素材
└── corner.png    角落素材（没选就没有这个文件）
```

## ⚠️ 素材需自行准备

**本仓库不包含任何角色素材。** 角色形象版权属于原作者，公开分发有侵权风险，
因此 `app/src/main/assets/pet/` 已被 `.gitignore` 排除。

**直接从本仓库 clone 下来是跑不出桌宠的** —— 需要自己准备图片。

### 放置位置

```
app/src/main/assets/pet/<角色目录>/
├── pet.json      尺寸清单
├── corner.png    「右下角」形态（贴右 / 下边时用）
└── upright.png   「直立」形态（贴左 / 上边时用）
```

目录名随意取（用角色名即可）。程序启动时扫描 `assets/pet/` 下**所有含 `pet.json` 的子目录**，
每个都成为一个可选角色。

### pet.json 格式

```json
{
  "name": "显示名称",
  "corner":  { "file": "corner.png",  "w": 1440, "h": 1352 },
  "upright": { "file": "upright.png", "w": 1024, "h": 875 }
}
```

- `name`：界面上显示的角色名，也用在「呼出 / 收起」按钮上
- `w` / `h`：对应 PNG 的**实际像素尺寸**，必须一致

### 素材要求

- **PNG 带透明通道**
- 两套形态都要：`corner` 是朝向左上方的右下角姿态，`upright` 是正立姿态
- 四周留白没关系 —— 程序按**非透明像素的包围盒**定位边界，留白会自动裁掉
- 建议高度 800～1500 px：太小放大后发虚，太大占内存

左侧不需要单独出图：渲染时对右侧素材做水平镜像，实测
`flip(镜像(右下角)) == 左下角`（像素差异 0.00）。

## 自己构建

### 环境

| 需要 | 版本 |
|---|---|
| JDK | 17+（开发用的是 Temurin 21） |
| Android SDK | `platforms;android-36`、`build-tools;36.0.0` |
| Gradle | 用仓库自带的 wrapper，无需另装 |

在项目根目录建 `local.properties`（**已在 `.gitignore` 里，不要提交**）：

```properties
sdk.dir=你的 Android SDK 路径
```

### 构建

```bash
./gradlew assembleDebug          # 调试包
./gradlew testDebugUnitTest      # 单元测试（85 个）
./gradlew assembleRelease        # 发布包
```

### 发布签名

签名信息从 `local.properties` 读取；**不填就跳过签名**、release 产出未签名包，
不影响 `assembleDebug` 与单元测试：

```properties
signing.storeFile=keystore/your.jks
signing.storePassword=***
signing.keyAlias=***
signing.keyPassword=***
```

自备密钥库：

```bash
keytool -genkeypair -v -keystore keystore/your.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias youralias
```

> ⚠️ 不要把签名口令写进 `build.gradle.kts` —— 那个文件会进仓库，等于把口令公开。

## 代码结构

```
app/src/main/java/com/dsh/deskpet/
├── MainActivity.kt     设置界面
├── PetService.kt       前台服务：悬浮窗生命周期、通知、屏幕开关
├── PetView.kt          桌宠本体：绘制、触摸、压缩回弹、吸附动画
├── PetSprite.kt        素材加载、镜像翻转、按状态缓存位图（内置 + 自定义两种来源）
├── CustomSkinStore.kt  自定义形象：导入图片、落盘、列举、删除
├── PetState.kt         分区 / 吸附 / 朝向规则 —— 纯逻辑，可单测
├── Prefs.kt            偏好读写
└── AccentTheme.kt      按角色发色给整套界面配色

tools/                  开发期辅助脚本（素材处理、图标生成、验证截图）
ENGINEERING.md          实现笔记与踩坑记录
```

`PetState.kt` 刻意做成**不依赖 Android 的纯逻辑**，所以吸附与朝向规则可以直接跑单元测试，
不需要模拟器。

## 权限说明

| 权限 | 用途 |
|---|---|
| `SYSTEM_ALERT_WINDOW` | 悬浮窗 —— 桌宠的核心，没有它什么都做不了 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | 常驻前台服务，桌宠才能在后台一直显示 |
| `POST_NOTIFICATIONS` | 前台服务的常驻通知（Android 13+ 需运行时授权） |
| `RECEIVE_BOOT_COMPLETED` | 开机自启（可选，默认关闭） |
| `VIBRATE` | 触摸反馈 |

App **不联网、不收集任何数据**，所有设置只存在本机 `SharedPreferences` 里。
