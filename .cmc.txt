动画恢复为 0115 版本手感；松手贴边改为"边转边靠、转在前完成"

用户指定 0115 版本（提交 7b15b00）的镜像动画与旋转动画手感最好，
唯一不足是"素材未旋转时松手贴边也不会旋转"。本次只改这一点。

## 1) 动画恢复成 0115 的参数

逐项对齐 7b15b00：
  SNAP_MS = 220   位移补间
  FLIP_MS = 200   跨中线镜像翻转（上一版被我改成 110，太快像硬切）
  ROT_MS  = 180   旋转
  HOP_MS  = 380   单击轻跳
  SQ_MAX  = 0.22  点击压缩比例

并逐行核对：
  - startFlip 实现与 0115 一致（都是带过渡的动画）
  - onDraw 里翻转绘制 `canvas.scale(squash, 1f, cx, cy)` 与 0115 完全相同
  - hitsPet 里对应的逆变换也一致
删掉上一版新增的 ROT_SNAP_MS（不再需要特例时长）。

## 2) 松手贴边：一边旋转一边靠近，且旋转先完成

settleInternal 里若需要旋转，旋转与位移**同时**开始：
  startRotAnim(shownRotation, wantRot)          // ROT_MS  = 180ms
  animateTo(targetCenterX, targetCenterY, SNAP_MS)  // 220ms
旋转时长是位移的 ~82%，所以**吸附到边框之前旋转就已经完成**。

注意该分支已当场处理状态与尺寸，必须把 pendingState 置 null，
否则位移补间结束时 applyPendingState 会把旋转再做一遍。

解冻（onRotationDone）统一为"保持素材中心点不动 + 重摆窗口"，
位置补间继续朝目标走，最终仍精确贴边（目标中心点按 want 的足迹算）。

25 个单测全绿。
